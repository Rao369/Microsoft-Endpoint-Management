# Problem Statement

During routine Windows Update for Business (WUfB) monitoring, approximately **1,800 Windows devices** reported the following alert:

**DeviceDiagnosticDataNotReceived**

Although these devices were Microsoft Intune managed and successfully receiving Windows Updates, diagnostic telemetry required for Windows Update for Business reporting was either missing or incorrectly configured.

This resulted in incomplete reporting and reduced visibility into update compliance across the enterprise.

---

# Business Impact

The issue affected several operational areas:

* Reduced Windows Update for Business reporting accuracy
* Large number of telemetry-related alerts
* Lower confidence in compliance dashboards
* Increased operational effort to investigate affected devices
* Reduced visibility into Windows servicing health

---

# Environment

* Microsoft Intune
* Windows Update for Business (WUfB)
* Windows 10
* Windows 11
* Microsoft Entra ID Joined devices
* Enterprise environment with approximately 3,800 managed endpoints

---

# Investigation

The following areas were reviewed during troubleshooting:

* Windows diagnostic data policies
* Registry configuration under DataCollection
* Windows Update for Business telemetry requirements
* Microsoft Intune policy application
* Device synchronization status
* Compliance reporting trends

The investigation identified that required telemetry registry values were missing or incorrectly configured on many affected devices.

---

# Root Cause

Windows Update for Business requires specific diagnostic data settings to upload compliance information.

On affected devices:

* Required registry values were missing or incorrect.
* Diagnostic data settings were not fully enforced.
* Devices therefore failed to submit the telemetry required for Windows Update reporting.

---

# Solution

A Microsoft Intune Proactive Remediation package was developed.

## Detection

The detection script validates:

* Registry path:

  * `HKLM:\SOFTWARE\Policies\Microsoft\Windows\DataCollection`
* `AllowTelemetry`
* `AllowUpdateComplianceProcessing`
* `AllowCommercialDataPipeline`

If any value is missing or incorrect, the device is marked non-compliant and remediation is triggered.

---

## Remediation

The remediation script performs the following actions:

1. Create the DataCollection registry path if required.
2. Configure `AllowTelemetry = 3`.
3. Configure `AllowUpdateComplianceProcessing = 1`.
4. Configure `AllowCommercialDataPipeline = 1`.
5. Record execution details in a local log file.

This lightweight approach standardizes telemetry settings without requiring user interaction or a device reset.

---

# Results

| Metric                                 | Before | After |
| -------------------------------------- | -----: | ----: |
| DeviceDiagnosticDataNotReceived Alerts |  ~1800 |   ~30 |

The solution significantly improved telemetry reporting accuracy and reduced the operational effort required to investigate missing diagnostic data alerts.

---

# Lessons Learned

* Correct telemetry configuration is essential for Windows Update for Business reporting.
* Microsoft Intune Proactive Remediation provides an effective method for enforcing configuration at scale.
* Registry-based remediation can resolve reporting issues without disruptive system changes.
* Continuous monitoring of telemetry health improves long-term compliance visibility.
