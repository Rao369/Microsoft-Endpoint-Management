# KB-005 – Enterprise Windows Update Health Orchestrator

## Purpose

This knowledge base documents the enterprise Windows Update remediation solution developed using Microsoft Intune Proactive Remediation.

The objective of the solution is to automatically detect and repair common Windows Update issues before they impact patch compliance, Windows Update for Business (WUfB) reporting, or endpoint health.

---

# Business Problem

During monthly Windows Update compliance reporting, the following recurring issues were observed:

* Devices below the approved monthly patch baseline
* Windows Update services stopped or disabled
* Missing Windows Update scan activity
* "Device Not Scanned" status in Windows Update reports
* Reduced overall patch compliance

Although many devices were operational, these conditions prevented successful Windows Update scans and reduced compliance across the environment.

---

# Solution Overview

The solution consists of two components:

## Detection

The detection script validates:

* Windows Build (CurrentBuild)
* Update Build Revision (UBR)
* Recent Windows Update events
* Windows Update service status
* Background Intelligent Transfer Service (BITS)
* Update Session Orchestrator (UsoSvc)

If any validation fails, Intune Proactive Remediation triggers the remediation script.

---

## Remediation

The remediation script performs staged recovery using the following sequence:

1. Check for pending reboot.
2. Validate Windows Update services.
3. Correct service startup configuration if required.
4. Start stopped services.
5. Refresh Windows Update settings.
6. Trigger Windows Update scan.
7. Trigger update download.
8. Trigger update installation.
9. Execute advanced recovery after repeated failures.
10. Record execution details in the remediation log.

---

# Intelligent Escalation

The remediation supports staged recovery.

Normal execution performs lightweight recovery actions.

Advanced recovery is triggered when the configured failure threshold is reached.

Advanced recovery includes:

* System File Checker (SFC)
* DISM RestoreHealth
* Windows Update cache reset

This staged approach reduces unnecessary repair operations while providing deeper recovery for persistently unhealthy devices.

---

# Logging

The remediation creates the following directory:

```text
C:\ProgramData\IntunePR
```

Files generated:

```text
WU_Master.log
WU_State.txt
```

## WU_Master.log

Contains:

* Execution time
* Service validation
* Windows Update actions
* Escalation status
* Completion status

---

## WU_State.txt

The production implementation reads a persisted failure count from this file to determine whether advanced recovery actions should be executed.

**Production Note**

The original production script reads the state value but does not automatically update it during execution.

Future versions of the solution may enhance this mechanism by automatically maintaining the failure count between remediation cycles.

# Windows Update Services

The remediation validates the following services:

| Service      | Purpose                                 |
| ------------ | --------------------------------------- |
| wuauserv     | Windows Update                          |
| bits         | Background Intelligent Transfer Service |
| UsoSvc       | Update Session Orchestrator             |
| WaaSMedicSvc | Windows Update Medic Service            |

If a required service is stopped, the remediation attempts to restore it automatically.

---

# Windows Update Actions

The remediation uses USOClient to initiate Windows Update operations.

Actions performed:

* RefreshSettings
* StartScan
* StartDownload
* StartInstall

These actions refresh Windows Update configuration and initiate the normal Windows Update workflow.

---

# Advanced Recovery

If escalation criteria are met, the following recovery actions are performed:

## System File Checker

```text
sfc /scannow
```

Repairs corrupted or missing protected Windows system files.

---

## DISM

```text
DISM /Online /Cleanup-Image /RestoreHealth
```

Repairs Windows component store corruption.

---

## Windows Update Cache Reset

Stops Windows Update services and recreates:

* SoftwareDistribution
* Catroot2

This resolves many Windows Update metadata and download issues.

# Lessons Learned

The project highlighted several operational best practices:

* Validate device health before initiating remediation.
* Avoid unnecessary deep repair actions.
* Perform lightweight recovery first.
* Use staged escalation for persistent issues.
* Maintain detailed execution logs for troubleshooting.
* Continuously review monthly patch baselines and update UBR values after each Patch Tuesday release.
